# La Jueguería

Breve descripción:
Aplicación web estática para el catálogo de juegos de mesa de La Jueguería. Incluye navegación por categorías, fichas de productos, sección de juegos destacados y formulario de registro con validaciones en JavaScript.

## Estructura de carpetas

```text
juegueria.cl/
|-- index.html
|-- README.md
`-- assets/
	|-- css/
	|   |-- bootstrap.min.css
	|   `-- styles.css
	|-- img/
	|   |-- categoria-estrategia.svg
	|   |-- categoria-familiares.svg
	|   |-- categoria-fiesta.svg
	|   |-- categoria-infantiles.svg
	|   |-- juego-estrategia.svg
	|   |-- juego-familiares.svg
	|   |-- juego-fiesta.svg
	|   `-- juego-infantiles.svg
	`-- js/
		|-- bootstrap.bundle.min.js
		`-- form-validation.js
```

## Tecnologías utilizadas

- HTML5 para la estructura del sitio.
- CSS3 para estilos personalizados, diseño visual y animaciones.
- Bootstrap 5 para apoyo en grillas responsivas y componentes de formulario.
- JavaScript para validaciones del formulario y cambios dinámicos en el DOM.
